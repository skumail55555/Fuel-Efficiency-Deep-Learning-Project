# Fuel Efficiency Deep Learning Project 🚗

This project predicts vehicle fuel efficiency (MPG) using Deep Learning techniques.

## Technologies Used
- Python
- TensorFlow
- Keras
- Scikit-learn
- Streamlit
- Pandas
- NumPy

## Deep Learning Concepts Applied
- ANN (Artificial Neural Network)
- CNN (1D Convolutional Neural Network)
- Activation Functions (ReLU)
- Optimizers (Adam & RMSprop)
- Dropout Regularization
- Model Evaluation Metrics

## Features
- Fuel efficiency prediction
- ANN model training
- CNN model training
- Streamlit web application
- Model comparison

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Feature Scaling
4. ANN Model Building
5. CNN Model Building
6. Model Training
7. Model Evaluation
8. Web App Deployment

## Web App
The Streamlit app allows users to input:
- Cylinders
- Displacement
- Horsepower
- Weight

and predict MPG instantly.
